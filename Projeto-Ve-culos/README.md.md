# Análise de Anúncios de Veículos (Vehicle Market Analysis)

Este aplicativo web interativo foi desenvolvido em Python utilizando **Streamlit**, **Pandas** e **Plotly Express** para analisar dados de anúncios de vendas de carros nos Estados Unidos.

## 🚀 Funcionalidades
- Visualização de distribuições de preços e quilometragem dos veículos.
- Gráficos de dispersão para explorar a relação entre o preço e outras variáveis (como ano do modelo e hodômetro).
- Filtros interativos para explorar diferentes categorias e fabricantes.
